# 关联项目

上方四个项目目录集中展示这套学习工程。点击目录即可进入对应仓库的固定代码版本，各项目原有的章节和提交历史仍在各自仓库中。

| 学习顺序 | 项目 | 主要内容 |
|---|---|---|
| 1 | [agent_ctrip_assistant](https://github.com/ooo1208/agent_ctrip_assistant) | 工具调用、预订提案、人工审批、会话恢复 |
| 2 | [RAG](https://github.com/ooo1208/RAG) | 文档检索、引用与可选混合检索 |
| 3 | [Text2SQL](https://github.com/ooo1208/Text2SQL) | 采购分析、SQL 只读执行与指标口径 |
| 4 | [ERP_OPENCLAW](https://github.com/ooo1208/ERP_OPENCLAW) | 综合采购 Agent 与评估闭环 |

一次下载所有代码：

```sh
git clone --recurse-submodules https://github.com/ooo1208/Agent-Learning.git
```

详细用法见 [目录使用说明](../docs/repository-folders.md)，学习路线见[总入口](../README.md)。
